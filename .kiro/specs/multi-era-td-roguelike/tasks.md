# 任务列表 -- 万代国 Phase 0 核心原型

## 概述

本文档将 Phase 0 核心原型的开发拆分为可执行的开发任务。任务按依赖关系排序，每个任务应在完成后使项目处于可编译状态。

---

## 任务 1：项目初始化与核心框架

**优先级**：P0  
**预计工时**：1 天  
**依赖**：无

### 目标
创建 Unity 项目标准目录结构，实现核心框架类（ServiceLocator、EventBus、IGameSystem 接口）。

### 子任务
- [x] 1.1 创建 Unity 项目目录结构（Assets/Scripts/Core, Systems, Config, Presentation, Enums 等）
- [x] 1.2 实现 IGameSystem 接口
- [x] 1.3 实现 ServiceLocator 静态类
- [x] 1.4 实现 EventBus 发布/订阅系统
- [x] 1.5 定义所有游戏事件结构体（GameEvents.cs）
- [x] 1.6 定义枚举类型（GameState, CellState, TargetingStrategy, RewardType）

### 验收标准
- 所有核心框架类可编译通过
- EventBus 支持泛型事件的发布与订阅

**依赖**：任务 1, 2

### 目标

### 子任务

- [x] 3.2 实现 GridMapSystem 核心逻辑（初始化、状态查询、状态修改）
- [x] 3.3 实现 LoadFromConfig 方法，从 MapConfig 加载地图布局

### 验收标准

- 支持查询任意格子的可建造状态
- 出生点与核心点可正确获取

## 任务 4：A* 寻路模块

**优先级**：P0  
**预计工时**：1 天  
**依赖**：任务 3

### 目标
实现 A* 寻路算法，支持从出生点到核心点的路径计算。

### 子任务
- [x] 4.1 实现标准 A* 算法（曼哈顿距离启发、四方向移动）
- [x] 4.2 实现 FindPath 方法
- [x] 4.3 实现 HasValidPath 验证方法
- [x] 4.4 实现路径缓存机制（网格变化时清除）

### 验收标准
- 能在 20x15 地图上正确计算最短路径
- 无路径时返回空列表或不可达状态
- 路径正确绕过 Blocked 和 Occupied 格子

## 任务 5：建筑系统

**优先级**：P0  
**预计工时**：1 天  
**依赖**：任务 3, 4

### 目标
实现建筑放置、移除逻辑，包含路径验证和资源检查。

### 子任务
- [x] 5.1 实现 BuildingInstance 数据类
- [x] 5.2 实现 BuildingSystem（CanPlace, Place, Remove, GetAllBuildings）
- [x] 5.3 集成路径验证：放置前检查是否会阻断所有路径
- [x] 5.4 集成资源检查：放置前验证资源是否足够

### 验收标准

- 放置后网格状态正确更新

## 任务 10：奖励系统

**优先级**：P0  
**预计工时**：1 天  
**依赖**：任务 1, 2

### 目标
实现波后三选一奖励的抽取与应用。

### 子任务
- [x] 10.1 实现 RewardCard 数据类
- [x] 10.2 实现 RewardSystem（DrawRewards 加权随机抽取、去重）
- [x] 10.3 实现三种奖励类型的应用逻辑：
  - NewBuilding：解锁新建筑蓝图
  - ResourceBonus：直接获得资源
  - BuildingUpgrade：强化已有建筑属性

### 验收标准
- 每次抽取 3 张不重复奖励卡
- 奖励按权重随机
- 三种奖励类型正确应用效果

## 任务 11：GameCore 状态机与游戏循环集成

**优先级**：P0  
**预计工时**：1 天  
**依赖**：任务 3-10

### 目标
实现 GameCore 主状态机，集成所有系统完成完整单局循环。

### 子任务
- [x] 11.1 实现 GameCore 状态流转：Initializing -> Preparation -> Combat -> Settlement -> RewardSelection -> Preparation（循环）-> Victory/Defeat
- [x] 11.2 实现各状态的进入/退出逻辑
- [x] 11.3 集成胜负判定：核心血量归零 = 败，所有波次完成 = 胜
- [x] 11.4 实现 Tick 主循环调度（分发给各子系统）

### 验收标准
- 状态正确流转，不出现非法跳转
- 准备阶段允许建筑操作，战斗阶段禁止
- 胜负条件正确触发
- 所有子系统按阶段正确 Tick
